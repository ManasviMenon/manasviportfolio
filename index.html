PlanCheck: NSW Planning Compliance Checker

Turns a residential address into a buildable envelope, resolving live NSW cadastre and zoning data against ~1,100 rules extracted from council DCP/LEP/SEPP PDFs via an LLM structure-detection pipeline. Setback geometry computed per-edge with Shapely instead of a naive averaged buffer. A companion Rhino/Grasshopper plugin extrudes that envelope into a real 3D mass, so architects get instant site constraints without leaving the tool they already design in. Deployed live on Render + Vercel. Built during a selective residency program.
